# Beta 3.3 — shared metadata candidate

Adds automatic Firebase anonymous authentication, per-installation credential protection, persistent offline metadata queue, shared all-laptops directory, cached central timing/recovery defaults and visible sync status. Exam files and student details remain local. No device approval or daily Firebase login.

Also simplifies session actions, schedules student-control closure after Finish, and includes the exact reported Posit login host.

Scope: not a production exam kiosk. Shared staff/PIN publishing, a web editing portal, PIN-only privileged machine operations, automatic online preflight verification and closing only the session-owned Edge instance remain follow-up work. Do not claim these have been fixed by this build.

See CloudSync/SETUP-STATUS.md for deployed Firebase state, testing limits, console editing guidance and two-laptop acceptance checklist. No student data has been used in validation.
